# Security policy

Please do not publish vulnerabilities that could cause unintended input,
persistent key/button state, unsafe pairing behavior, or exposure of device
identifiers. Report them privately through GitHub's security-advisory feature.

Include the affected commit, phone model, Android version, host operating system,
connection mode, and minimal reproduction steps. Remove Bluetooth addresses,
computer names, serial numbers, and unrelated logs before attaching evidence.

Only the latest commit on the default branch is currently supported.
